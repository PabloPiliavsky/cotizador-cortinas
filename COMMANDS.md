# Atajos y Comandos de Desarrollo (Antigravity Commands)

Este directorio contiene los comandos y prompts estructurados diseñados para automatizar tareas repetitivas de revisión, refactorización, pruebas y documentación en el proyecto.

## Índice de Comandos Disponibles

- **[/review.md](file:///c:/Users/Pablo/Desktop/updated-agent/commands/review.md)** (`/review`): Invoca a **El Crítico** para auditar el código buscando problemas de seguridad, manejo de errores y mantenibilidad.
- **[/refactor.md](file:///c:/Users/Pablo/Desktop/updated-agent/commands/refactor.md)** (`/refactor`): Invoca a **El Optimizador** para aplicar principios de Clean Code y mejorar rendimiento sin alterar la funcionalidad.
- **[/test.md](file:///c:/Users/Pablo/Desktop/updated-agent/commands/test.md)** (`/test`): Genera suites completas de pruebas unitarias y de integración que cubran caminos felices y de borde.
- **[/docs.md](file:///c:/Users/Pablo/Desktop/updated-agent/commands/docs.md)** (`/docs`): Genera documentación directa y técnica para APIs y componentes, actualizando el archivo global `DOCUMENTATION.md`.
- **[/debug.md](file:///c:/Users/Pablo/Desktop/updated-agent/commands/debug.md)** (`/debug`): Inicia un diagnóstico estructurado "Chain of Thought" para encontrar la causa raíz y solución óptima de un bug.

---

## Modo de Uso
Para ejecutar cualquiera de estos comandos:
1. Lee las instrucciones específicas contenidas en el archivo `.md` respectivo de la carpeta `commands/`.
2. Adopta el rol e identidad indicados.
3. Devuelve los resultados estructurados según el formato requerido.
